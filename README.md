🚀 Hướng dẫn cài đặt

1. Yêu cầu hệ thống
   Python 3.8 trở lên.

2. Cài đặt thư viện
   Mở terminal và chạy lệnh sau để cài đặt toàn bộ thư viện cần thiết (bao gồm xử lý tín hiệu và giao diện Web):

- pip3 install mne matplotlib pandas yasa streamlit plotly

🛠 Cách chạy dự án

- Chạy ứng dụng Web Validator (Khuyên dùng)
  Đây là cách tốt nhất để đối chiếu file tín hiệu EDF với các đặc trưng trong file CSV.

- - Mở terminal tại thư mục dự án.

- - Chạy lệnh: streamlit run app.py

- - Trình duyệt sẽ tự động mở giao diện Validator Pro. Tại đây bạn có thể chọn bệnh nhân, chọn Epoch và xem tín hiệu thời gian thực.

- File ipynb mở và chạy thôi
